# Example: “How to choose a project management tool for a small business” (FAQ)

This is a complete unattended research-first run for Issue #4. It targets the United States in English and answers a selection question without pretending to test or endorse a product.

| Stage | Files | Result |
|---|---|---|
| 1 Brief | [01-brief.md](01-brief.md) | Defines the FAQ intent, audience, and evidence limits. |
| 2 Discover | [02-discover.md](02-discover.md) | Records reader questions, queries, and observed pages. |
| 3 Read and score | [03-scores.md](03-scores.md), [pages.json](pages.json) | Scores three pages using observable signals. |
| 4 Analyse | [04-analysis.md](04-analysis.md) | Extracts strengths, gaps, and short verified quotes. |
| 5 Baselines | [05-baselines.md](05-baselines.md) | Assigns one role to each baseline. |
| 6 Research brief | [06-research-brief.md](06-research-brief.md) | Provides must-covers, differentiators, and the facts ledger. |
| 7 Outline | [07-outline.md](07-outline.md) | Plans six answer-first FAQ questions and a checklist. |
| 8–9 Write and edit | [article.md](article.md) | Produces a grounded, vendor-neutral FAQ. |
| 10–11 Judge and report | [review-report.md](review-report.md) | Records scores, limitations, and the image handoff. |

All sources were read on 2026-11-02. The article contains no prices, percentages, decimals, or first-hand claims; every quoted source passage is 25 words or fewer and is credited in the ledger.
